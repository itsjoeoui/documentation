Throughout the official Nominal Instrumentation documentation on this site, you will find **example code snippets** inline with the topics being described. Those snippets are meant to highlight specific concepts and usage patterns in context.

For **full, runnable examples** that you can copy and adapt for your own projects, Nominal publishes a dedicated examples site that is updated as we add more examples.

# Published examples

The [Nominal Instrumentation SDK Examples](https://nominal-io.github.io/instrumentation-docs/examples/) site hosts complete, functional examples organized by instrument type and use case. The examples page is updated as Nominal creates more examples, so check back for new content.

Examples on that site include:

- **DAQ** — analog and digital read/write, hardware- and software-timed acquisition, with and without background daemons
- **Device discovery** — querying instrument identity information
- **Electronic loads** — ELoad usage
- **I2C** — basic and command-based I2C examples
- **Power supplies** — PSU usage with and without a background worker
- **Publishers** — buffered, custom, and queued publishing
- **Test rack** — end-to-end test rack demo
