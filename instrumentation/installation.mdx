<Info>The Nominal Instrumentation Library is in alpha testing for some of our customers. If you would like to try out the Instrumentation Library, but do not currently have access, please reach out to us through our [Support Portal](https://portal.usepylon.com/nominal).</Info>

Nominal Instrumentation is available natively via Nominal Connect or available by accessing private PyPi package repository.

# Nominal Connect
This is the easiest install path available for Nominal Connect users. Simply add the `nominal-instro` package to your packages list in your `app.connect` file. Utilize any [additional packages](#additional-packages) to install more support.

```yaml
python:
  packages:
    - nominal-instro[daq]
```

When Nominal Connect builds your python environment for you, Nominal Instrumentation will be installed to it automatically.

# Manual installation with pip
A deploy token is required to install from the Nominal repository. Please reach out to your Nominal representative or our [Support Portal](https://portal.usepylon.com/nominal) so Nominal can create a deploy token for you.

1. Acquire a deploy token from your Nominal representative.
2. Activate your Python virtual environment.
3. Install via `pip`
``` bash
(.venv) > pip install "nominal-instro>=0.1.0" --extra-index-url https://<DEPLOY_TOKEN>@pypi.fury.io/nominal/
```
<Info>There is a version of `0.0.0` in the public PyPI. This is meant to reserve the name. If you do not explicitly state a higher version, pip will grab the `0.0.0` from the public PyPI.
We will install versions ≥ `0.1.0` to force pip to fallback to the Nominal private repository, hosted by GemFury, and grab the latest version.</Info>

## Additional Packages

Nominal Instrumentation has additional packages for utilizing vendor instruments that require their own dependencies. This allows you to install only the vendor Python dependencies you need.
<Info>This is in reference to python dependencies. See [Driver Dependencies](/instrumentation/driver-dependencies) as external installers are required for some instruments.</Info>

To install additional packages, add the names of the groups to you pip installation command. For example:
``` bash
(.venv) > pip install "nominal-instro[<GROUP_NAME>]>=0.1.0" --extra-index-url https://<DEPLOY_TOKEN>@pypi.fury.io/nominal/
```

### DAQ
 - To install the LabJack package, use `labjack`.
 - To install the NI DAQ package, use `nidaq`.
 - To install all the aforementioned daq packages, use `daq`.

### I2C
 - To install the TotalPhase Aardvark package, use `aardvark`.
 - To install all the aforementioned i2c packages, use `i2c`.

### All
 - To install all of the aforementioned packages, use `all`.

Example:
 ``` bash
(.venv) > pip install "nominal-instro[all]>=0.1.0" --extra-index-url https://<DEPLOY_TOKEN>@pypi.fury.io/nominal/
```
